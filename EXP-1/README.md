## Overview

This experiment demonstrates the implementation of Artificial Neural Networks (ANNs) using TensorFlow for both regression and classification tasks. The models were trained and evaluated using appropriate performance metrics.

## Software Used

- Python
- TensorFlow
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset

### Regression
- **Dataset:** California Housing Dataset
- **Source:** Scikit-learn
- **Samples:** 20,640
- **Features:** 8
- **Target:** Median House Value

### Classification
- **Dataset:** Scikit-learn Classification Dataset
- **Task:** Multi-class Classification

## Model

- Feedforward Artificial Neural Network
- Dense hidden layers
- ReLU activation for hidden layers
- Linear output for regression
- Softmax output for classification

## Evaluation Metrics

- **Regression:** MSE, MAE, RMSE
- **Classification:** Accuracy and Loss

## Outcome

The ANN successfully learned both regression and classification tasks, demonstrating how neural networks can model continuous values as well as categorical outputs.
