## Overview

This experiment compares different activation functions and optimization algorithms to study their impact on neural network performance and convergence.

## Software Used

- Python
- TensorFlow
- Matplotlib
- Google Colab
- GitHub

## Dataset

- **Dataset:** MNIST Handwritten Digits
- **Training Samples:** 60,000
- **Testing Samples:** 10,000

## Activation Functions Compared

- Sigmoid
- Tanh
- ReLU

## Optimizers Compared

- SGD
- Momentum
- RMSProp
- Adam

## Evaluation Metrics

- Training Accuracy
- Validation Accuracy
- Training Loss
- Validation Loss
- Convergence Speed

## Key Observations

- ReLU achieved faster convergence than Sigmoid and Tanh.
- Adam produced the best overall optimization performance with quicker convergence and lower loss.
- Validation accuracy improved consistently with ReLU and Adam.
