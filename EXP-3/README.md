## Overview

This experiment implements a Convolutional Neural Network (CNN) to classify real-world images using a benchmark image dataset and analyzes its performance through accuracy, loss curves, confusion matrix, and prediction results.

## Software Used

- Python
- TensorFlow/Keras
- Matplotlib
- Google Colab

## Dataset

- **Dataset:** Intel Image Classification
- **Source:** Kaggle
- **Classes:** Buildings, Forest, Glacier, Mountain, Sea, Street

## CNN Architecture

- Convolution Layers
- ReLU Activation
- Max Pooling Layers
- Fully Connected Layers
- Softmax Output Layer

## Evaluation Metrics

- Training Accuracy
- Validation Accuracy
- Testing Accuracy
- Training Loss
- Validation Loss

## Performance Analysis

- Accuracy and loss were visualized using epoch-wise graphs.
- A confusion matrix was generated to evaluate class-wise predictions.
- Misclassified images were analyzed to understand model limitations.

## Outcome

The CNN successfully learned meaningful image features and demonstrated effective performance on multi-class image classification tasks.
