# GENERATION OF SYNTHETIC IMAGES USING A GENERATIVE ADVERSARIAL NETWORK (GAN)

## Description

This experiment implements a Generative Adversarial Network (GAN) using the MNIST handwritten digit dataset to generate synthetic images. The GAN consists of two neural networks: a Generator and a Discriminator. The Generator creates synthetic images from random noise vectors, while the Discriminator distinguishes between real images from the dataset and fake images generated by the Generator. Both networks are trained using an adversarial learning framework to improve the quality and realism of generated images.

## Dataset

- **Dataset:** MNIST Handwritten Digit Dataset
- **Training samples:** 60,000
- **Testing samples:** 10,000
- **Image dimensions:** 28 × 28 pixels
- **Image type:** Grayscale
- **Number of classes:** 10 (Digits 0–9)
- **Pixel value range:** 0 to 255
- **Normalized pixel range:** -1 to 1

## Data Preprocessing

- Loaded the MNIST dataset using TensorFlow/Keras.
- Explored the dataset and displayed sample handwritten digit images.
- Examined image dimensions and pixel-value ranges.
- Converted image data into floating-point format.
- Normalized pixel values from the range 0–255 to -1–1.
- Reshaped images into 28 × 28 × 1 format.
- Prepared shuffled batches of real images for GAN training.

## GAN Model Architecture

- **Model:** Generative Adversarial Network (GAN)
- **Architecture:** Fully Connected GAN
- **Latent noise dimension:** 100
- **Generator layers:** 128, 256, 512 and 784 neurons
- **Discriminator layers:** 512, 256 and 1 neuron
- **Hidden layer activation:** Leaky ReLU
- **Generator output activation:** Tanh
- **Discriminator output:** Logits
- **Optimizer:** Adam
- **Learning rate:** 0.0002
- **Loss function:** Binary Cross-Entropy
- **Training epochs:** 20
- **Batch size:** 128

## Generator and Discriminator

**Generator:**

The Generator takes a 100-dimensional random noise vector as input and transforms it into a synthetic 28 × 28 grayscale image. Its objective is to generate realistic images that can fool the Discriminator into classifying them as real.

**Discriminator:**

The Discriminator receives both real images from the MNIST dataset and synthetic images from the Generator. It learns to distinguish between real and fake images through binary classification.

Both networks are trained alternately using adversarial learning to improve the quality of synthetic image generation.

## GAN Training and Performance Monitoring

- Trained the Discriminator using real and generated images.
- Trained the Generator to produce realistic synthetic images.
- Alternated the training of both networks.

- Plotted the loss values against the number of epochs.

## Observations

- The Generator initially produced random noise-like images.
- As training progressed, the Generator learned to produce recognizable handwritten digit-like images.
- The Discriminator learned to distinguish between real and generated images.
- Generator and Discriminator losses fluctuated during adversarial training.
- Different random noise vectors produced different synthetic images.
- The quality and diversity of generated images depended on training stability and model performance.
- The experiment demonstrated the importance of adversarial learning in synthetic image generation.

## Result

A Generative Adversarial Network was successfully implemented and trained using the MNIST handwritten digit dataset. The Generator produced synthetic images from random noise vectors, while the Discriminator distinguished between real and generated images. The training performance was monitored using Generator and Discriminator loss graphs, and the generated synthetic images were visualized and compared with original dataset samples.

## Conclusion

The experiment demonstrated the architecture and working of Generative Adversarial Networks for synthetic image generation. The Generator learned to create new images from random noise, while the Discriminator evaluated whether the generated images were real or fake. Through adversarial training, both networks improved their performance, enabling the Generator to produce realistic synthetic handwritten digit images. The experiment provided an understanding of adversarial learning, loss functions, training processes and practical applications of GANs.
